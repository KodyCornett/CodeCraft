## 2. Codex-tier (login-gated) documents to consume the existing secrets

The first batch gave us 15 non-codex pages, each hiding one secret/credential in an
HTML comment (e.g. `COPPER_HEAVY_99`, `UNLINK_THE_GRID`, `SIGNAL_PERSISTS_2026`,
`HARMONIC_RESONANCE_441`, `AV-8809-SUB-BYPASS`, `STA_SUB_LEVEL_03`,
`ITRON_NET_BYPASS`, the 1988 hatch code `1889`, etc.). None of them have anywhere to
be used yet — we need the actual locked pages those credentials open.

Write 3-5 Codex-tier pages. Each one needs:

- **Title** and a short **header-only preview** (the part visible before login —
  should tease what's behind it without giving it away).
- **One or more credential fields**, each with a **label** (e.g. `access_code`,
  `netid`, `passphrase`) and the **expected answer**. Reuse the secrets already
  hidden in the 15 pages — don't invent new ones. A page can require just one
  credential (easy) or two-plus from different source pages (harder, forces the
  player to cross-reference multiple documents).
- **Which non-codex pages are its "leads"** — i.e., which of the 15 already-written
  pages point toward this credential (a player should be able to trace: read page →
  notice the hidden comment → recognize it belongs to a different locked page).
- **What's revealed on successful login** — the real payoff content.
- A **reward tier** (small creds/tech-point number, doesn't need to be exact).

Good candidate groupings based on what's already written: the Monroe Street Bridge /
Substation 09 tap (ties AVISTA, ITRON, WIRE-DEAD, NULL together), the GONZAGA lab
access (`HARMONIC_RESONANCE_441`), and the COPPERHEAD/Knuckle steel-smuggling thread
(`COPPER_HEAVY_99`). Use your judgment on the rest.
